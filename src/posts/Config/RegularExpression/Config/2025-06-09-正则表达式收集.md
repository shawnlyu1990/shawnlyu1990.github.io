:::: details **禁止操作 o2db 数据库的表，或禁止登录 o2db 数据库**

正则表达式

```regexp
(^(.+)[oO][2][dD][bB].+)|([uU][sS][eE] [oO][2][dD][bB])
```

匹配效果

```sql
-- 以下操作全匹配
SELECT * from o2db.abc;
SELECT * from o2DB.abc;
use o2db
USE O2DB
```

:::: details **匹配不含 where 关键词的操作命令**

正则表达式

```regexp
^(?=.*)(?!.*where).*$
```

匹配效果

```sql
-- 不匹配
SELECT * from o2db.abc where id =1;

-- 匹配
SELECT * from abc;
```
