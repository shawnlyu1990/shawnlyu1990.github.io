:::: details **创建数据库**

```sql title="创建数据库并指定默认字符集为 UTF-8"
CREATE DATABASE IF NOT EXISTS your_db_name DEFAULT CHARSET utf8 COLLATE utf8_general_ci;
```

```sql title="创建数据库并指定默认字符集为 GBK"
CREATE DATABASE IF NOT EXISTS your_db_name DEFAULT CHARACTER SET gbk COLLATE gbk_chinese_ci;
```

:::: details **备份和恢复数据库**

#### **备份单个库**

```bash title="备份单个数据库"
mysqldump -u username -p dbname [tablename ...]> filename.sql
```

::: note

对上述语法参数说明如下：

- **`username`**：表示数据库用户名；
- **`dbname`**：表示需要备份的数据库名称；
- **`tablename`**：表示数据库中需要备份的数据表，可以指定多个数据表。省略该参数时，会备份整个数据库；
- **`filename.sql`**：表示备份文件的名称，文件名前面可以加绝对路径。通常将数据库备份成一个后缀名为 `.sql` 的文件。

:::
::: important
`mysqldump` 命令备份的文件并非一定要求后缀名为 `.sql`，备份成其他格式的文件也是可以的。例如，后缀名为 `.txt` 的文件。通常情况下，建议备份成后缀名为 `.sql` 的文件。因为，后缀名为 `.sql` 的文件给人第一感觉就是与数据库有关的文件。
:::

#### **备份多个库**

```bash title="备份多个数据库"
mysqldump -u username -p --databases dbname1 dbname2 ... > filename.sql
```

::: note
加上 `--databases` 参数后，必须指定至少一个数据库名称，多个数据库名称之间用空格隔开。
:::

#### **备份所有库**

```bash title="备份所有数据库"
mysqldump -u username -p --all-databases > filename.sql
```

::: note
使用 `--all-databases` 参数时，不需要指定数据库名称。
:::

#### **恢复数据库**

```bash title="恢复数据库"
mysql -u username -p [dbname] < filename.sql
```

::: note

- **`username`**：表示用户名称；
- **`dbname`**：表示数据库名称，该参数是可选参数。如果 filename.sql 文件为 mysqldump 命令创建的包含创建数据库语句的文件，则执行时不需要指定数据库名。如果指定的数据库名不存在将会报错；
- **`filename.sql`**：表示备份文件的名称。

:::

::: important
如果使用 `--all-databases` 参数备份了所有的数据库，那么恢复时不需要指定数据库。因为，其对应的 sql 文件中含有 `CREATE DATABASE` 语句，可以通过该语句创建数据库。创建数据库之后，可以执行 sql 文件中的 `USE` 语句选择数据库，然后在数据库中创建表并且插入记录。
:::
